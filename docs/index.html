Run from Source

Clone the repository and run the automated PowerShell setup script to create .venv, download models, and launch silently. 

git clone https://github.com/sharif-git-dev/whisper-flow.git
cd whisper-flow
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
wscript start_silent.vbs
